Student Record Management System

Python Programming Mini Project

1. Project Overview

The Student Record Management System is a menu-driven, console-based application developed using Python. The main purpose of this project is to manage student information in a simple and organized way.

The system stores student details such as roll number, name, course/class, and marks. It allows users to perform different operations through a menu and saves records in a text file for future use.

3. Problem Statement

Maintaining student records manually can be time-consuming and make it difficult to search, update, and organize information. This project provides a simple Python-based solution to perform these operations efficiently.

4. Objectives

- To create a basic student record management application.
- To store student details in an organized format.
- To provide options for adding, viewing, searching, updating, and deleting records.
- To save records in a text file using file handling.
- To apply Python programming concepts in a practical project.

5. Work Completed in the Project

The following functionalities have been implemented in the program:

1. Add Student: Accepts a student's roll number, name, course/class, and marks.
2. View All Students: Displays all available student records in a readable format.
3. Search Student: Searches for a student using the roll number.
4. Update Student: Allows existing student information to be modified.
5. Delete Student: Removes a selected student record.
6. File Handling: Saves student records in "student_records.txt" and loads them when the program starts.
7. Input Validation: Checks for empty or duplicate roll numbers and validates marks between 0 and 100.
8. Menu-Driven Interface: Provides a simple menu for selecting different operations.
9. Error Handling: Handles invalid numeric input and file access errors.

6. Python Concepts Used

- Variables and Data Types: Store student details and user choices.
- Lists and Dictionaries: Store and organize student records.
- Functions: Divide the program into separate operations.
- Loops: Repeat the menu until the user exits.
- Conditional Statements: Execute operations according to the selected menu option.
- Input and Output: Accept user information and display results.
- File Handling: Read and write student records in a text file.
- Exception Handling: Handle invalid numeric input and file errors.

7. Tools and Technologies

- Programming Language: Python 3
- Data Storage: Text file
- Development Environment: Python-compatible editor or terminal
- External Libraries: Not required

8. How the Program Works

1. The program starts and loads previously saved student records.
2. A menu displays the available operations.
3. The user selects an operation.
4. The program performs the selected task and displays the result.
5. Updated records are saved to the text file.
6. The menu continues until the user selects Exit.
