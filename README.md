Project Description

The Student Record Management System is a console-based application developed using Python. It helps users maintain student information, including roll number, name, course/class, and marks.

The system allows users to add, view, search, update, and delete student records. It uses file handling to save records in a text file so that the information can be loaded when the program runs again.

Objectives

- Store student information systematically.
- Display all student records in a readable format.
- Search for students using their roll numbers.
- Update existing student details.
- Delete unwanted student records.
- Save and load records using file handling.
- Apply fundamental Python programming concepts.

Features

1. Add Student: Enter a student's roll number, name, course/class, and marks.
2. View All Students: Display all saved student records.
3. Search Student: Find a student using their roll number.
4. Update Student: Modify existing student details.
5. Delete Student: Remove a student record.
6. Save Records: Store student information in a text file.
7. Input Validation: Check duplicate roll numbers and validate marks.

How to Run the Project

Step 1: Clone or download this repository.

git clone https://github.com/YOUR-USERNAME/Student-Record-Management-System.git

Replace "YOUR-USERNAME" with your GitHub username.

Step 2: Open the project folder.

cd Student-Record-Management-System

Step 3: Run the Python program.

python student_record_management_system.py

If your system uses "python3", run:

python3 student_record_management_system.py
